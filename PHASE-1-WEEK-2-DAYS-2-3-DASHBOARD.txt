API ENDPOINTS
════════════════════════════════════════════════════════════

🔓 RBAC Endpoint (Public, Auth Required)
   GET /api/rbac/permissions?action=...
   
   Actions:
   - my-permissions      Returns current user's permissions
   - all-roles          Returns all roles and permissions
   - categories         Returns permissions by category
   - role-permissions   Returns specific role permissions

📝 Admin Endpoints (Permission-Based)
   POST /api/admin/users
   Requires: users.create permission
   Creates new user in system

👨‍🏫 Faculty Endpoints (Permission-Based)
   POST /api/faculty/attendance
   Requires: attendance.create permission
   Submits class attendance records
